# Implementation prompts

Five independent Kiro implementation prompts, one per workstream. **Do not run
these yet** — the implementation approval gate is CLOSED. They are the authorized
delegation briefs to use **after** the architecture is approved.

Every prompt assumes the agent first reads, in authority order: `AGENTS.md`,
`Addiotional Info 1.txt`, `architecture.md`, `docs/mathematical-model.md`,
`docs/weekly-state-machine.md`, `contracts/`, `docs/integration-plan.md`,
`docs/end-to-end-walkthrough.md`, then the primary plan and the blueprint. Each
agent edits only its owned files (see `AGENTS.md` §5), adapts to the frozen
contracts, and reports with the "definition of done" (`AGENTS.md` §7).

Files: `01-seir.md`, `02-fdna.md`, `03-data-accessibility-eval.md`,
`04-hospital-allocation-scenario.md`, `05-orchestration-streamlit-integration.md`.
